# 🐍 Introdução ao Desenvolvimento Backend com Python

Repositório dedicado aos estudos e exercícios desenvolvidos durante a seção **Introdução ao Desenvolvimento Backend com Python**, da formação Backend da EBAC.

O objetivo é registrar e praticar os conceitos fundamentais da linguagem Python, desde a configuração do ambiente até a construção de programas.

## 📚 Conteúdo estudado

### Módulo 1 — Configuração, Sintaxe e Gerenciamento de Pacotes

Módulo introdutório sobre a linguagem Python, seus fundamentos e ferramentas utilizadas no desenvolvimento.

**Conteúdos abordados:**

- Configuração do ambiente Python;
- Execução de scripts Python;
- Variáveis e tipos de dados;
- Operadores matemáticos;
- Gerenciamento de ambientes virtuais e dependências com Poetry.

**Observação:** Alguns conteúdos precisaram ser estudados além do que foi ensinado diretamente no módulo para desenvolver a atividade prática: [Calculadora em Python](https://github.com/gabriellysaless/calculadora_python).

Os conteúdos complementares estudados foram:

- Entrada de dados com `input()`;
- Conversão de tipos;
- Estruturas condicionais (`if`, `elif` e `else`);
- Estruturas de repetição (`for` e `while`).

## 🛠️ Tecnologias e ferramentas

- Python
- Poetry
- Git e GitHub
- Visual Studio Code

## 🎯 Objetivo

Desenvolver uma base sólida em Python, compreendendo os fundamentos da programação e preparando o ambiente para os próximos passos no desenvolvimento Backend.

Este repositório será atualizado conforme o avanço nos módulos desta seção.
